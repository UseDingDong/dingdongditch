# Support

DingDongDitch is early-stage open-source software maintained on a best-effort
basis.

- When GitHub Discussions is enabled, use it for usage questions, design
  questions, and ideas that are not yet actionable issues.
- Use the issue templates for reproducible bugs, scoped feature requests, and
  documentation improvements.
- Review the README, examples, and `Engineering/` documentation first.
- Follow `SECURITY.md` for vulnerabilities; never report them publicly.

There is currently no paid support, service-level agreement, guaranteed
response time, or guarantee that a proposed feature will be accepted.
